## Workflow-fit discussions

For GitHub workflow-fit questions, start from the documentation and examples in
this repository.

Please keep questions concrete where possible:

- what workflow you are trying to support
- what command or step you ran
- what failed or was unclear
- whether the issue concerns docs, diagnostics, workflow fit, or product scope

## Scope note

This repository is the public documentation, Action-wrapper, and adoption
surface for Tobi Validator.

It is not a claim of:

- runtime/backend availability
- public verification API availability
- broader platform availability
- unrestricted public access to the production validator implementation
- automatic availability of later Organetic product surfaces
